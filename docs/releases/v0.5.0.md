# LLMSlim v0.5.0

LLMSlim can now read MCP tool catalogs and prepare complete tool contracts for an agent host. Tool execution and authorization stay with your application.

## Package

- Optional `llmslim[mcp]` supports Streamable HTTP and literal-argv stdio through the official MCP Python SDK.
- Bounded pagination, scoped TTL caching, catalog fingerprints, and stale-plan detection.
- Full and measure-only plans preserve the entire authoritative catalog. Selective exposure remains opt-in and research-only.
- Optional `llmslim[agents]` exposes an OpenAI Agents SDK bridge with an explicit host callback.
- Offline `llmslim tools inspect` catalog inspection.
- Cache-copy isolation, refresh invalidation, and strict bridge/plan matching fixes found during release review.

MCP and Agents extras require Python 3.10+. Base compression remains available on the existing supported Python versions.

## Website

A redesigned landing page, light/dark modes, custom dimensional artwork, hover and scroll effects, and an MCP integration guide. Official Sarvam co-branding marks LLMSlim's acceptance into the Sarvam Startup Program. Studio includes request cancellation, timeouts, and clipboard error handling. Existing indexing infrastructure is preserved.

## Validation

Local Python 3.12: **507 tests passed, 90.62% branch coverage**. Real local MCP HTTP and stdio tests, Agents host callback tests, Ruff, MyPy, distribution checks, isolated wheel import, and Next.js production build passed. The legacy benchmark retains warnings against its old compression baseline; this release makes no universal compression, latency, or live-model success claim.

```sh
pip install --upgrade llmslim==0.5.0
pip install 'llmslim[mcp]==0.5.0'
pip install 'llmslim[agents]==0.5.0'
```
