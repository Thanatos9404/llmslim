## Release boundaries

- Stable: tool representation, supported provider normalization, canonical JSON,
  fingerprints, exact contract checks, copied authoritative schema preservation,
  and safe catalog optimization.
- Research-only: lexical/dense/hybrid retrieval, selective exposure, context
  planning, and lazy hydration. Retrieval does not authorize or execute tools.
- Semantic model: optional `intfloat/multilingual-e5-small` at pinned revision
  `0e60b8d9d2166d80387f86e3b48ec9ced55f4d15`; weights are not packaged.
- ToolRet: partial attempt only; no external score may be claimed.

## Measured Phase 4.6 status

The canonical `benchmarks/results/latest.json` is generated with LLMSlim
0.4.0. Its dynamic policy measurements are: BM25 all-required recall 98.25%,
selective coverage 25.89%, fail-open 74.11%; dense E5 98.54%, 18.02%, and
81.98%; hybrid RRF 98.54%, 10.91%, and 89.09%. Every strategy has zero median
tokens avoided. This supports a conditional Phase 4.6 pass only under the
research-only boundary.
