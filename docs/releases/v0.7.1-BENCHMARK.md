## Measured local KV continuation

A separate ten-trial CPU experiment used a randomly initialized, two-layer
Llama model with a 128-token prefix and one appended token. Median full
forward time was **1.8032 ms**; median cached continuation was **1.1589 ms**
(35.7% lower for that second forward). Maximum absolute difference in final
logits was **0.00000013**. Prefill happened before the continuation timing;
the comparison reflects a prior turn whose prefix had already been processed.
This verifies the local Transformers integration on a tiny model, not provider
TTFT, useful answer quality or production-model speedup. Reproduce with
`python benchmarks/v071_local_kv.py`; data are in
`benchmarks/results/v0.7.1-local-kv.json`.
