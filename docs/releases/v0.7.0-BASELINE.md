## Reproduction

Use a Python 3.12 environment with project dev dependencies. On this host,
the original virtual environments reference a Python executable that is no
longer present, so a bundled Python was used with the existing `venv` site
packages on `PYTHONPATH`.

```text
python -m pytest --basetemp .release-v07-baseline-pytest
python -m ruff check .
python -m mypy llmslim benchmarks/v06_planner.py benchmarks/live_sarvam_v06.py
python -m build --no-isolation --sdist --wheel --outdir .release-v07-baseline-dist
python benchmarks/v06_planner.py --output docs/releases/v0.7.0-v06-baseline.json --report docs/releases/v0.7.0-v06-baseline-benchmark.md
cd web && npm run lint && npm run build
```
