## Known limits

- v0.3.1 is a Python release. It does not ship an npm package, Rust engine, ONNX runtime, or WASM runtime.
- Rewrite and hybrid modes require a caller-supplied provider.
- The calculator/model-price catalog is maintained separately from this release documentation commit; users should validate pricing and workload results independently.
