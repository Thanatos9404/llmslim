# LLMSlim v0.6.0 implementation checklist

This checklist was derived from the repository at `9072428` before v0.6
implementation began. It is an engineering work log, not a claim that an
unchecked gate passed.

## Baseline audit

- [x] Version: `0.5.0` in `pyproject.toml` and `llmslim/__init__.py`.
- [x] Build backend: setuptools (`setuptools.build_meta`).
- [x] Declared Python raised to 3.9+ to match the exercised CI matrix and source/tooling baseline.
- [x] Base dependencies: NumPy, scikit-learn, jsonschema.
- [x] Existing extras: semantic, MCP, Agents, fast-tokens, NLP, structured, all, dev.
- [x] Public compression, chat/RAG pipeline, rewrite-provider, token and cost APIs audited.
- [x] ContextRole provenance and compression-induced instruction-elevation controls audited.
- [x] Tool canonicalization, SHA-256 fingerprints and exact contract equivalence audited.
- [x] MCP snapshots, pagination, cache scope/TTL, stale-plan hydration and host adapters audited.
- [x] FULL and MEASURE_ONLY remain production-safe; SELECTIVE remains explicit and experimental.
- [x] CLI, benchmark suite, packaging, release gates and Next.js Studio audited.
- [x] Baseline: 505 passed, 3 optional-MCP skips, 90.58% coverage.
- [x] Baseline Ruff: pass.
- [x] Baseline MyPy failures resolved while retaining the MCP 2.x `httpx2` transport.
- [x] Baseline wheel/sdist: pass.

## Core planner

- [x] Immutable/safely copied context, candidate, decision, budget, profile and plan models.
- [x] Deterministic multiple-choice constrained optimization.
- [x] Explainable scoring, adaptive candidates and policy presets.
- [x] Explicit infeasible plans; never truncate required trusted instructions silently.
- [x] Post-plan validation and conservative candidate fallback.
- [x] Stable `plan_context()` and `AdaptiveContextPlanner` APIs.
- [x] Existing compression, RAG/chat and MCP/tool-context integration.
- [x] Local-only telemetry and estimated/provider-reported measurement labels.

## Optional integrations

- [x] Sarvam official-SDK rewrite provider, model profiles, INR cost telemetry and live opt-in eval.
- [x] ContextSource/ContextStore abstractions and in-memory implementations.
- [x] Zoho CRM and WorkDrive bounded, read-only, untrusted context sources.
- [x] PyMongo async context store plus bounded Atlas text/vector retrieval source.
- [x] Credentials excluded from repr, plans, telemetry, errors and artifacts.

## Product surfaces and evidence

- [x] `llmslim plan` CLI while preserving legacy CLI behavior.
- [x] Studio adaptive-planner input, result and decision visualization.
- [x] Catalyst-compatible hosted-demo template and documented wallet-credit uncertainty.
- [x] Same-origin hosted Sarvam route with a default-off kill switch and server-only credentials.
- [x] MongoDB-backed distributed rate, token, concurrency, and atomic spend controls.
- [x] Pseudonymous identity derivation, strict payload caps, sanitized errors, and aggregate-only telemetry.
- [x] Frozen chat/RAG/tool/mixed/external/multilingual corpus and four baselines.
- [x] English, Hindi, Hinglish and nine additional Indic-language cases.
- [x] Threat-model update, API/integration docs, migration notes and runnable examples.
- [x] Version, README, changelog, citation, release notes and security support table updated.
- [x] Full tests, coverage >=90%, Ruff, MyPy, build, artifact inspection and secret scan pass.
- [x] Base and optional-extra clean-install checks pass.
- [x] Offline benchmark generated; live Sarvam result clearly marked not run.
- [x] Final `docs/releases/v0.6.0-RELEASE_GATE.md` contains exact commands and results.
