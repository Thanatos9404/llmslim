# LLMSlim v0.7.0 engineering report

Status: **0.7.0 GitHub source release**. Package metadata, `__version__`, and
the Studio dependency target `0.7.0`. The wheel is stored in `web/vendor` and
referenced by a hash-pinned URL to the `v0.7.0` tag.
PyPI publication and hosted deployment have not been verified.
Evidence here is local and offline unless stated otherwise. See the
[frozen baseline](v0.7.0-BASELINE.md) and [new benchmark](v0.7.0-BENCHMARK.md).

1. **Starting state.** HEAD was `43b8c774ad5d95d22a0b7b1176ac201fd1514a4e`.
   Package metadata and `__version__` were `0.6.0`. The pre-existing edits to
   `web/AGENTS.md`, `playground-1.mongodb.js`, and `upload.sh` were left alone.
2. **v0.6 baseline.** 596 tests passed, three optional MCP tests skipped,
   branch coverage was 90.70%, and Ruff, MyPy, wheel/sdist, web lint/build
   passed. The frozen 28-case adaptive benchmark achieved 96.4% budget success,
   100% hard/fact/tool retention, 11.4% reduction, and 126.33 ms mean latency.
3. **Architecture.** Explicit inputs flow through envelope, policy, graph,
   progressive planner, quality report, plan, model input, and local trace.
   Model and tool execution remain with the host.
4. **ContextEnvelope.** Reuses v0.6 `ContextItem` and provenance types; copies
   metadata, validates IDs, limits item counts, and omits bodies from default
   serialization.
5. **Context Graph.** Builds bounded, deterministic explicit dependency,
   call/result, reply, source, and same-entity edges. Only dependency edges
   constrain selection; graph links cannot grant trust.
6. **Planner 2.0.** Starts raw, generates bounded candidate frontiers only
   under pressure, and chooses reductions by utility loss per token saved.
   A failed budget is reported as infeasible without silent truncation.
7. **Quality gates.** Checks trusted instructions, declared facts, numbers,
   entities, similarity, coherence, structure, dependencies, tools, and query
   relevance separately. These local checks do not prove model answer quality.
8. **Context policies.** Mandatory roles, source lists, token caps, stale tool
   results, and caller-provided redaction run before planning.
9. **ContextRuntime.** `prepare_sync()` handles local turns; async `prepare()`
   retrieves explicitly configured sources and demotes them to untrusted
   evidence. It does not call a model or execute a tool.
10. **Sessions.** Opt-in, bounded, process-local history is keyed by caller
    session ID. The host records assistant responses; no automatic persistence
    or cross-session reuse occurs.
11. **ContextTrace.** Contains hashed IDs, decisions, token estimates,
    timings, cost estimates, and safe warnings; prompt bodies are omitted.
12. **Provider adapters.** Generic, Sarvam, and OpenAI-compatible request
    helpers return detached data. The host owns credentials and the API call.
13. **Agent framework integration.** A text-only OpenAI Agents SDK
    `call_model_input_filter` prepares context before each model call and
    rejects complex SDK items until their contract can be preserved.
14. **MongoDB/Zoho.** Existing source classes can be passed explicitly to
    async preparation. Retrieval is read-only; MongoDB save remains explicit.
15. **MCP.** Existing FULL, MEASURE_ONLY, and experimental SELECTIVE paths,
    schema fingerprints, and tool-contract controls are unchanged.
16. **Security.** External roles and control metadata are demoted; credential
    metadata is rejected; graph bounds and trace redaction are tested. Prompt
    delimiters are not a sandbox, and host authorization remains essential.
17. **Studio.** The Context Inspector shows before/after categories, named
    quality gates, decisions, graph edges, trace, and model-visible context.
    Inputs are compact and responsive; the sample now exercises reduction.
    Invalid budgets and JSON have actionable errors.
18. **Benchmark corpus.** 112 frozen cases across chat, long chat, RAG,
    memory, tools, external context, mixed context, and multilingual inputs.
    SHA-256: `c91a8ea2bfa9b70f6c54b1759eb43440bf73864a7658b4d5d70140db6e888d40`.
19. **v0.6 versus v0.7.** On the expanded corpus, v0.6 adaptive reached
    86.6% budget success, 86.6% required-fact retention, and 26.9% reduction.
    v0.7 reached 67.9%, 100%, and 18.7%, respectively. The v0.7 quality
    protection trades more infeasible plans for complete measured fact retention.
20. **Maximum Safe Context Reduction.** Observed mean 30.8%, median 30.8%,
    range 0.0%–94.5% over five budget probes per case. This is an offline
    observed lower bound, not a universal optimum.
21. **Performance.** v0.7 mean planning latency was 51.34 ms on this run;
    v0.6 adaptive was 65.90 ms on the same expanded corpus. Token counts and
    costs are estimates; latency varies with hardware and Python environment.
22. **Tests.** 623 passed, three explained optional MCP skips, zero failures.
    A protected pytest cache path produced one non-test warning.
23. **Coverage.** Branch coverage was 90.20%, above the project 90% minimum
    and below the frozen v0.6 90.70% due to added runtime surface. More branch
    cases are desirable before publication.
24. **Ruff.** PASS on the repository after the final code changes.
25. **MyPy.** An earlier package and benchmark check passed. The final standard
    invocation hit a third-party Torch MyPy internal error. A scoped check with
    dependency following skipped and the pre-existing `var-annotated` warning
    disabled found no issues in 50 package files.
26. **Build/install.** Wheel and sdist build with `--no-isolation`; a local
    0.7.0 wheel in `dist/` installs and imports with `--no-deps`; the same wheel
    is bundled in `web/vendor`, and the web requirement references the tagged
    wheel by URL and SHA-256; `pip check` passes. Clean
    isolated base/extras installs remain unverified because package downloads
    are unavailable in this environment.
27. **Web build.** Next.js production build passed for 35 static pages with
    two data workers. Lint passed with 23 pre-existing warnings and zero errors.
28. **Known limitations.** Local quality checks cannot establish real-model
    answer correctness; token counts are estimated; process-local sessions do
    not survive restart; complex SDK tool items are unsupported by the new hook.
29. **Experimental features.** Existing MCP SELECTIVE mode remains
    experimental. The v0.7 runtime and Studio are a release candidate until
    deployment and clean install gates pass.
30. **Remaining work before public release.** Run clean installs for declared
    Python versions and extras, opt-in real-model evaluations, deploy the
    Studio with its tagged 0.7.0 wheel, and complete hosted E2E. PyPI
    publication remains a separate release step. The local development API
    loads this repository's 0.7.0 source directly.
31. **Recommended release notes.** Lead with the per-turn runtime, explicit
    sessions, provenance graph, quality-gated progressive planning, safe trace,
    and agent integration. State the measured fact/budget tradeoff plainly.
32. **Recommended v0.8 priorities.** Improve multilingual relevance and
    budget feasibility, add provider-reported token accounting, validate
    contract-safe complex SDK items, and measure end-to-end answer quality.
