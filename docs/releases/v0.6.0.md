# LLMSlim 0.6.0 release notes

LLMSlim 0.6 introduces the Adaptive Context Planner: a deterministic,
provider-neutral budget allocator for instructions, chat history, RAG, memory,
tool results, and authoritative tool schemas. It preserves the existing
compression API while exposing explainable per-item decisions, explicit
infeasibility, validation, token/cost telemetry, and policy presets.

First-class optional integrations add Sarvam rewrite/model profiles, bounded
read-only Zoho CRM and WorkDrive sources, and explicit PyMongo async memory and
Atlas retrieval. All three stay out of the base installation.

The release includes a 28-case frozen offline benchmark spanning chat, RAG,
tools, mixed context, mocked external sources, English, Hindi, Hinglish and
nine additional Indic languages. Live Sarvam evaluation remains a separately
opted-in paid command and was not run during normal release validation.

Security remains conservative: ranking is not authorization, tools are never
executed, raw contracts remain authoritative, external content remains
untrusted, and trusted instructions are not silently truncated.

Studio now has two explicit execution modes. Offline Planner performs no model
call. Sarvam AI — Hosted Demo, where an operator enables it, sends the planned
context through the official SDK using a server-only key. Paid mode defaults
off and requires a durable MongoDB operational ledger, an HMAC identity secret,
strict payload and output limits, sliding network/session quotas, per-identity
token limits, atomic project daily/monthly spend reservations, expiring
concurrency slots, aggregate-only telemetry, and the environment kill switch
`LLMSLIM_HOSTED_SARVAM_ENABLED`.

The hosted response clearly separates pre-call `ESTIMATED` usage/cost from
`PROVIDER_REPORTED` usage. The route never returns provider/database secrets,
raw stack traces, authorization headers, or abuse-scoring internals. BYOK is
deliberately absent from the public Studio.

Python 3.9 is now the declared minimum, matching the CI matrix. The package
continues to keep provider and database SDKs behind optional extras.
